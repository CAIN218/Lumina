# BrightSwitch

Windows用の常駐型モニター明るさ調整ツールです。
DDC/CI対応の外部モニターの明るさを、グローバルホットキー1つで即座に上げ下げできます。

- 複数モニターを同時に、それぞれの現在値からの相対調整で明るさ変更
- 調整時にはトースト通知で現在の明るさを表示
- Windows起動時の自動起動に対応
- 設定画面からモニターごとにスライダーで直接調整も可能

## 対応環境

- Windows 10 / 11
- DDC/CI対応モニター(HDMI/DisplayPort接続の外部モニターの多くが対応)。
  ノートPCの内蔵ディスプレイはWindows標準の明るさ調整を使ってください(DDC/CI非対応)。
- お使いのモニターがDDC/CIに対応していない場合、設定画面で「DDC/CI対応モニターが
  見つかりませんでした」と表示されます。モニターのOSDメニューでDDC/CIを
  有効にできる場合があります。

## 使い方

### 1. 初回起動・設定

`BrightSwitch.exe`(または`python brightness_switch.py`)を起動すると設定画面が開きます。

1. **MONITORS** に検出されたモニターと現在の明るさが表示される。スライダーで直接調整可能
2. **明るく** / **暗く** の欄をクリックし、使いたいキーの組み合わせを押してホットキーを設定
   (初期値: 明るく=`ctrl+alt+up`、暗く=`ctrl+alt+down`)
3. **STEP** でホットキー1回あたりの変化幅(%)を設定(初期値: 10)
4. Windows起動時に自動で立ち上げたい場合は **Start on boot** をON
5. **Save & Run** で設定を保存してそのままバックグラウンド常駐開始(**Save only** は保存のみ)

### 2. 通常使用

常駐中はウィンドウは表示されません。設定したホットキーを押すたびに、接続中の
全モニターの明るさがそれぞれの現在値から指定したSTEP分だけ上下し、画面右下に
トースト通知で現在の明るさ(平均値)が表示されます。

### 3. 設定を変更したい場合

常駐中のBrightSwitchを一度終了し、`BrightSwitch.exe`を再度起動すると設定画面が
開きます(多重起動防止のため、古いプロセスは自動的に終了します)。

### 4. 終了方法

タスクマネージャーから`BrightSwitch.exe`を終了してください。

## 設定ファイル

exeと同じフォルダに以下のファイルが作成されます。

- `app_config.txt` — ホットキー(明るく/暗く)、STEP、自動起動設定
- `error.log` — エラー発生時のログ(トラブル時の調査用)

## 開発者向け: ソースからのビルド

```
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --noconfirm BrightSwitch.spec
```

`dist/BrightSwitch.exe` が生成されます。

## 設計メモ

AudioSwitcher(同シリーズの音声出力切り替えツール)と同じ設計方針を踏襲しています。

- ホットキーのコールバックは低レベルキーボードフックのコールバックスレッドから
  直接呼ばれるため、重い処理(DDC/CI通信)を直接行わずキューに投げるだけにして、
  別スレッドのワーカーで実処理する。AudioSwitcherで「常駐中しばらくするとホット
  キーが反応しなくなる」不具合の原因がまさにこれだったため、最初から適用している
- 常駐中のトースト通知用にTkのToplevelを1枚だけ使い回し、Tclインタプリタの
  再生成によるメモリ増加を防ぐ
